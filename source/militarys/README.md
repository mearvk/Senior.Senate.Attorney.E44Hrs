# Militarys

This directory is reserved for military-related source models and reference structures used by the project.

The plural directory name **militarys** is retained exactly as specified by the project structure.

Content should distinguish:
- organizational/reference models;
- historical or descriptive material;
- software representations;
- operational capabilities.

Repository source should not be represented as an official military system, command system, or government authority merely because it models military concepts.
