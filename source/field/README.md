# Field

This directory contains field-oriented source: operational fields, domain fields, field records, and structures that connect objects and conduct to a working context.

Keep field definitions explicit about:
- type and format;
- source and provenance;
- lifecycle;
- validation;
- whether a field is required or optional;
- whether it contains sensitive information.

Field names should describe data rather than imply authority or factual verification.
