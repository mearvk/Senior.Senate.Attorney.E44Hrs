# Tech

The `source/tech/` directory is reserved for technology-oriented source
models, interfaces, utilities, and implementation notes used by the project.

Suggested organization:

- Technology models and abstractions.
- C and C++ interfaces and implementations.
- Hardware and software capability representations.
- Technical standards, protocols, and interoperability notes.
- Verification and implementation documentation.

Technical descriptions in this directory should distinguish implemented
software from planned work, external standards, historical references, and
claims requiring independent verification.

This directory is a project source area. Its contents do not, by themselves,
establish government, military, legal, scientific, or institutional authority.
