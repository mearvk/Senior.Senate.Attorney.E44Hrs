# Objects

This directory contains object-oriented source and definitions for entities represented by the Senior Senate Attorney project.

Use this area for reusable object models, records, classes, and object-level representations. Keep domain objects separate from transport, field operations, and conduct rules.

- Prefer small, explicit models.
- Document ownership and lifecycle.
- Keep external identifiers and sensitive data clearly marked.
- Do not treat an object definition as proof that the represented entity exists outside the software.
