# Source

The `source/` directory is the organized source-development area for **Senior.Senate.Attorney.E44Hrs**.

## Structure

- `objects/` — reusable object models and entity representations.
- `militarys/` — military-related models and reference structures.
- `conduct/` — conduct rules, policies, behavioral and procedural logic.
- `field/` — field definitions, records, and operational data structures.

## Design Principle

Keep the four areas distinct while allowing them to compose:

**Objects** describe things.  
**Militarys** describe military-related domains and structures.  
**Conduct** describes rules and behavior.  
**Field** describes the data and context in which those structures operate.
